# Sphere Runner — Interactive Rehabilitation Game

A browser-based rehabilitation game developed using HTML, CSS and JavaScript. Sphere Runner combines interactive gameplay, custom canvas rendering and device-specific controls to create an engaging game experience.

The project demonstrates how web technologies can be used to implement interactive rehabilitation-oriented gameplay with visual and audio feedback.

## Features

- **Canvas-based rendering:** Custom 2D graphics and animations using HTML Canvas.
- **Interactive controls:** Hold-and-release mechanics for controlling the sphere.
- **Device selection:** Three interaction modes — glove, strap and cushion.
- **Collectibles and scoring:** Collect diamonds, earn points and track progress.
- **Obstacles and collision detection:** Navigate obstacles and interact with the game environment.
- **Game-state management:** Start, pause, resume and restart functionality.
- **Audio feedback:** Background music and sound effects for in-game events.
- **Performance tracking:** Score, collected diamonds and an in-game statistics screen.
- **Visual feedback:** Progress indicators, animations and interactive overlays.

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Web Audio

## Running the Game

1. Clone or download this repository.
2. Open `runner-game.html` in a web browser.
3. Select an interaction device.
4. Start the game and follow the on-screen instructions.
